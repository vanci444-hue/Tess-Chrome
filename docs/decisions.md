# Tess-Chrome 体验决策

## D-001 短录音识别与音频保留

- 日期与状态：2026-09-20；已替代。用户否决录后转写并选择实时字幕，当前选择见D-004；以下仅保留历史建议。
- 关联：REQ-002、AC-004、006、025；tech-spec API-009—011、§三生命周期、§五语音流程、§七配置。
- 问题：用户明确需要真实 ASR，但未要求录音期间实时显示字幕；两种方案的录音和等待方式不同。

| 方案 | 用户体验与代价 | 技术依据/未验证项 |
|---|---|---|
| A：录完后转写（推荐） | 销售录音时看到计时，停止后等待文字，再纠正和确认；没有边说边出字 | 官方 qwen3-asr-flash 接受 webm/opus、Base64；短录音不需公网音频地址。实际识别延迟、姓名金额效果未测 |
| B：边说边显示字幕 | 提前看到识别结果，但中间结果可能被更正；需要实时音频通道、断线恢复及更多侧栏权限验证 | 必须另行核验流式输入服务，不能把录音结束后流式输出文字当作实时字幕 |

- 建议：A；单段最多 5 分钟、10 MB，在官方约束内；超过时提示结束本段后继续追加复盘，不截断后假装全部识别。成功转写后删除本机临时音频，保留原转写及销售修正文本；失败音频最多临时保留 24 小时供显式重试，用户丢弃时立即删除。没有长期录音库、回放和云存储功能。
- 最终选择与确认依据：录后转写未被采用；旧24小时失败音频方案不再有效。当前选择与保留建议见D-004。
- 落地与验收：TC-03、TC-11；本机 Chrome 153 首次麦克风允许/拒绝、实际采音、停止录音、关闭 Side Panel 前后均需实测。若侧栏不能直接弹授权，先验证扩展自有授权页申请许可后回侧栏；不能擅自降级为仅上传文件。
- 来源：[官方 ASR 协议](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[音频规格](https://help.aliyun.com/zh/model-studio/asr-model)。没有把网页文档或 tab 音频捕获示例当成麦克风实测证明。

## D-002 扩展访问本机服务的规范适配

- 日期与状态：2026-09-20；用户已选插件形态的常规适配，随整体技术方案说明，不设置独立审批。
- 关联：全体扩展 HTTP API；tech-spec §二部署、§七配置与 TC-11。
- 问题：default 网页规范要求前端相对 `/api`，而 Side Panel 的 origin 为 `chrome-extension://`，相对路径不会指向 localhost。

| 方案 | 用户体验与代价 | 依据 |
|---|---|---|
| A：扩展请求模块直连配置的 loopback origin（推荐） | 安装扩展、启动本机服务后正常使用；Web Report 同源访问，不需第二套用户产品 | Chrome 扩展 host_permissions 支持跨源请求；配置锁定 loopback，后端 origin/Host 白名单 |
| B：将业务界面搬到 Web 页再嵌入 | 多一层页面/消息通信、录音与焦点流程也需重做验证 | 增加实现与测试范围，偏离已确认“插件主要形态”的直接实现 |

- 建议：仅 `frontend/src/services/` 扩展适配层读 `VITE_LOCAL_API_ORIGIN`，继续统一 Axios、/api 资源路径；Report 与 Vite Web 保留原规范。所有实际端口来自配置，HTTP例外仅限定 localhost/127.0.0.1，不扩展到任意网页请求。
- 最终选择与确认依据：用户已确认 Chrome Side Panel + FastAPI 本机服务形态；此技术适配在整体方案中明确，不要求用户单独选择规范例外、端口或跨源细节，也不自行修改仓库 default 规范。
- 验收：真实 unpacked extension 请求成功；恶意/未知网页 Origin 无法写入本机数据；扩展权限仅 Tesla 与 loopback；后端不对公网监听。
- 来源：[Chrome 跨源网络](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)。

## D-003 充电地图采用静态真实地图

- 日期与状态：2026-09-20；已替代。用户确认静态地图并要求可点击外部搜索，当前选择见D-005；以下保留历史比较。
- 关联：REQ-003、006 / AC-007、018、031、038；tech-spec API-012、016、018。
- 问题：用户要求真实充电设施、地图展示，但 Report 按钮为静态。本次不需要用户在 Report 中继续操作地图。

| 方案 | 用户体验与代价 | 依据 |
|---|---|---|
| A：高德真实静态地图＋站点/路线列表（推荐） | 看得到位置、编号和距离；不能拖动缩放。重新打开旧报告仍保留当时内容 | Web服务 API Key 同时用于检索、路线、静态图；服务端保存当次图像，无前端 Key 或动态远端脚本 |
| B：可拖动缩放 JS 地图 | 可自主探索，但要额外 JS Key/安全配置，扩展 CSP 和固定报告快照处理更复杂 | JS API 有独立安全配置；不能直接用 Web 服务 Key 替代 |

- 建议：A，销售改变查询区域仍由 Agent 重新调用真实服务，不影响真实查询要求；路线时间明确查询时估算。静态图失败保留站点列表和缺失标记。保存图片时保留高德标识，服务账户可用性与相关条款需真实接入核对，不自行裁掉标识。
- 最终选择与确认依据：静态图保留，并增加用户明确要求的高德搜索外链；详见D-005。
- 验收：TC-05、TC-07；地图编号与列表对应，旧链接不实时换图/重算；不暴露 key，不用示例图冒充查询成功。
- 来源：[静态地图](https://lbs.amap.com/api/webservice/guide/api/staticmaps)、[JS API 安全配置](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)。

## D-004 实时字幕、编辑后手动发送

- 日期与状态：2026-09-20；用户已明确选择实时ASR，替代D-001的录后转写建议。原音频不落盘策略已随本轮整体方案由用户明确确认。
- 关联：REQ-002 / AC-004、006、025、042；API-009、022、010、021，TC-03、17。
- 确认依据：用户明确“实时边说边显示文字，转写留输入框可手动编辑，必须手动点发送后Agent才处理，停止录音不自动发送”。
- 实现：独立ASR transport通过后端WSS访问 qwen3-asr-flash-realtime；VAD断句只更新字幕，finish完成识别不触发业务。供应商partial按item替换，final完成当前句；用户编辑或发送后迟到事件不能覆写。
- 代价：比短录音多一条实时流、采样与断流处理；麦克风权限、AudioWorklet、实际延迟和准确率仍需真实联调，不能承诺零延迟。
- 保留策略建议：PCM仅有界内存流转，不本机落盘；已有字幕留扩展本机草稿，手动发送才服务端持久化；断线不能从服务器重放音频，未识别部分补写/重录。ASR供应商会收到实时音频，不承诺其零留存。
- 验收：断流/尾句/重复结果/边录边改/切客户/侧栏关闭以及“停录不提交”；只有010/021手动发送后才出现业务run与Timeline销售消息。
- 依据：[官方实时交互](https://help.aliyun.com/zh/model-studio/qwen-asr-realtime-interaction-process)、[客户端事件](https://help.aliyun.com/zh/model-studio/qwen-asr-realtime-client-events)、[服务端事件](https://help.aliyun.com/zh/model-studio/qwen-asr-realtime-server-events)。

## D-005 静态地图与外部搜索

- 日期与状态：2026-09-20；用户已确认；替代D-003只做静态图的建议。
- 关联：REQ-003、006 / AC-007、017—018、031、038、043；API-016、018；TC-18。
- 确认依据：用户明确“静态地图可以，但点击地图可以进去搜索”；主智能体说明并按其指示落实为外部高德新标签页继续搜索，不在Report嵌入JS地图。
- 选择：Report保留当次静态真图＋站点列表；入口“在高德继续搜索”打开 `https://uri.amap.com/search`，只传编码后的区域/充电关键词、城市、view=map、src=tess-chrome、callnative=0。不传客户信息、Key或CRM文本。
- 限制：官方URI的center仅移动端有效，电脑端不保证复现报告中心和5km范围；新页由高德当前结果支持继续搜索/浏览，可能不同于报告快照，绝不回写。其余Ask Tess/联系/分享等业务按钮仍静态。
- 验收：真实Chrome新标签打开、中文编码及无敏感查询参数、报告重开保持旧图旧时间；实机点击尚未验证。
- 依据：[高德搜索URI](https://lbs.amap.com/api/uri-api/guide/search/search)。
