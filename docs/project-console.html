金融约束求解

Agent 工具 calculate_finance + 普通 Decimal 计算函数

源码已核对 · 不等于实机通过

实际官网车价与Mock金融规则分开；满足月供和首付约束，不承诺贷款审批。

输入：capture_id、product_id、首付上下限/明确首付、期限列表、月供上限（金额分）

输出：按总融资成本、首付、月供排序的每期方案或no_solution

算法、参数与失败处理

处理对象：有限期限的贷款约束

处理步骤

  • 校验费用、优惠、首付比例、期限和计息口径完整。net=车价+融资费用−优惠。支持zero_interest及明确月利率equal_payment。
  • 每个允许期限n计算factor：0息为1/n；等额本息为 r(1+r)^n/((1+r)^n−1)。由月供上限反推最小首付。
  • 首付下界取产品最小比例与销售下限较大值，上界取产品最大比例、销售上限和净额较小值。有限扫描最小首付起至最多n分修正舍入。
  • 月供按Decimal四舍五入到分；末期吸收剩余余额。普通月供及末期都不能超过预算；总融资成本包含费用。

条件与分支

  • 已移除/冲突Capture或车价单位不明不可计算；预算约束需要来自销售confirmed事实。
  • 不满足约束返回no_solution和未满足原因，不偷改预算；未知费用不当0。

结果如何选择

  • 排序key=(financing_cost_fen,down_payment_fen,monthly_payment_fen)；每期限取首个可行首付。

失败与边界

  • 不能把年化费率当利率；当前产品来源始终Mock。
